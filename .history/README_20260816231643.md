# Edufio — Penjadwalan Sesi Les Privat

Aplikasi penjadwalan les privat full-stack Next.js.

---

## 1. Cara Menjalankan Aplikasi dari Nol

1. **Install dependensi**:
   ```bash
   npm install
   ```

2. **Konfigurasi Environment Variable**:
   Buat file `.env.local` di root folder dan isi dengan string koneksi MongoDB Atlas:
   ```env
   MONGODB_URI=mongodb://tegarwijayaa71_db_user:M2cWB3YmsLjq1xNB@ac-lrzhkez-shard-00-00.bye4vst.mongodb.net:27017,ac-lrzhkez-shard-00-01.bye4vst.mongodb.net:27017,ac-lrzhkez-shard-00-02.bye4vst.mongodb.net:27017/?ssl=true&replicaSet=atlas-nbrg1t-shard-0&authSource=admin&appName=Cluster0
   ```

3. **Jalankan Aplikasi (Mode Dev)**:
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

## 2. Keputusan yang Diambil (Di Luar Brief)

* **Palet Warna Edufio**: Menyesuaikan UI dengan tema warna khusus (Teal utama `#026C7A`, Navy `#004153`, Kuning aksen `#FBC84F`) untuk memperkuat branding identitas aplikasi les.
* **Tombol Back**: Menambahkan tombol kembali (`backUrl`) di header Langkah 2 dan 3 untuk memudahkan user mengubah pilihan tanpa harus mengulang input pendaftaran dari nol.
* **Kalender Hari Senin**: Memulai kalender dari hari Senin agar mempermudah alur perencanaan jadwal les mingguan.

## 3. Hal yang Seharusnya Berbeda dari Brief

* **Pendaftaran Terintegrasi (Edit Mode)**: Seharusnya form pendaftaran di Langkah 1 mendeteksi jika user kembali dari langkah berikutnya sehingga form terisi otomatis (pre-filled), bukan mereset form.

## 4. Pembagian Kerja (AI vs Manusia)

* **Dikerjakan AI**:
  - Restrukturisasi komponen kalender (month navigation, dot indicator, Monday-first).
  - Validasi tabrakan waktu (conflict validation) secara dinamis & UI warning amber.
  - Implementasi koneksi database Mongoose & skema MongoDB.
  - Perbaikan styling variables Tailwind.
* **Dikerjakan Sendiri (User)**:
  - Memberikan brief visual referensi & penyesuaian alur.
  - Mengarahkan palet warna brand Edufio.
  - Melakukan pengujian alur secara berkala pada browser.

## 5. Apa yang Belum Selesai dan Kenapa

* **Fitur Edit/Hapus Sesi Terjadwal**: Sesi yang sudah masuk ke ringkasan belum bisa dihapus atau diedit secara individu secara langsung dari UI, karena brief awal fokus pada penambahan sesi baru hingga paket kuota terpenuhi.
